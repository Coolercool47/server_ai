
# 🧠 AI-Generated vs Human-Made Image Classifier Ensemble

Этот проект — исследование и реализация ансамбля моделей глубокого обучения для классификации изображений на **сгенерированные ИИ** и **созданные человеком**. Он построен на базе `PyTorch` и объединяет несколько архитектур: ResNet-50, Swin-T и CLIP, а также использует MLP в роли мета-модели.

## 🔍 Цель проекта

Разработка устойчивой и точной модели, способной отличать:

- ИИ-сгенерированные изображения (Midjourney, DALL·E, Stable Diffusion и др.)
- Изображения, созданные человеком (фотографии, цифровое искусство)

## 🧩 Используемые модели

- `ResNet-50` — сверточная сеть.
- `Swin-T` — архитектура на базе Vision Transformer.
- `CLIP` (от OpenAI) — соединяет визуальное представление и текстовое описание.
- `Meta-MLP` — простая полносвязная сеть, обученная на выходах трёх вышеуказанных моделей.
- Модели ResNet и Swin-t были дообучены на изображениях датасета Genimage и дополнительно датасетах изображений, сгенерированных YandexArt и Kandinskiy, модель Meta-MLP была дообучена на выходах всех трех моделей
- CLIP использовался только в режиме инференса 

## 🛠️ Архитектура ансамбля

1. Каждое изображение проходит через три независимые модели (`resnet`, `swin`, `clip`).
2. Их вероятностные предсказания объединяются в единый вектор признаков.
3. Этот вектор подаётся на `MetaMLP`, который обучается на основе этих признаков.
4. Финальный класс выбирается по выходу MLP.


## 📊 Результаты

| Model        | Accuracy |
|--------------|----------|
| ResNet-50    | 96%      |
| Swin-T       | 97%      |
| CLIP         | 79%      |
| Meta-MLP     | 92% |
